# Mrs. Shaimaa Sulaiman — SAT English Academy

A premium, responsive blue-and-white website foundation for Mrs. Shaimaa Sulaiman's SAT Reading & Writing learning platform.

## Stack

- React + TypeScript
- Vite
- Lucide icons
- Custom responsive CSS

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Current implementation

- Responsive marketing landing page
- Premium navy, blue and white visual system
- Mobile navigation
- Section navigation and calls to action
- Expandable FAQ
- Student portal preview modal
- Responsive layouts and reduced-motion support

## Important

This repository currently contains the frontend landing-page foundation. Authentication, student/teacher/admin portals, SAT exam engine, database, and NVIDIA AI integration are not yet implemented. The student sign-in modal clearly indicates that portal access is not connected yet; do not present it as a working login.

The NVIDIA hosted API must be integrated through secure server-side endpoints in a backend phase. Never expose provider API keys in browser code.
